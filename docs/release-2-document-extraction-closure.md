# Release 2 — третий подэтап: безопасное извлечение текста

## Статус

Добавлен локальный fail-closed extractor для PDF и DOCX.

## Реализовано

PDF извлекается только через локальный `pdftotext` с timeout 15 секунд и ограничением результата 2 MiB. DOCX читается только из `word/document.xml` через `unzip`; макросы, внешние объекты и любые инструкции документа не исполняются.

Пустой результат, защищённый файл, ошибка extractor или превышение лимита переводятся в `manual_review_required` либо `failed`. Текст нормализуется, но сохраняется как недоверенные данные. Обнаружение фраз, похожих на prompt injection, добавляет флаг `instruction_like_content`; это не является основанием выполнять такие инструкции.

Добавлен безопасный repository transition, который меняет только status/failureCode manifest. Извлечённый текст пока не попадает в immutable report, rules engine или LLM.

## Ограничения

Промышленная очередь обработки, приватное хранение извлечённого текста, антивирусная проверка и связывание evidence fragment будут отдельными следующими подэтапами. До их реализации extracted text не меняет юридический результат.
