# Release 1 — Web report: closure review и техническая приёмка

**Инкремент:** вертикальный инкремент 6 Release 1.
**Ветка:** `feat/lexy-release-1-web-report`.
**Режим:** только synthetic/test-only Pilot. Этот документ не является юридическим заключением и не снимает обязательную итоговую проверку человеком-юристом.

## Что реализовано

После успешной детерминированной оценки система создаёт ровно один неизменяемый web-отчёт из сохранённого snapshot. Содержимое отчёта формируется только сервером из зафиксированных ответов, результата правил, согласий и тестовой записи доступа. Браузер получает ограниченную проекцию: итог, риски, правовые основания, дорожную карту, рекомендации, ограничения и статус эскалации. Исходные ответы, внутренние идентификаторы, запись платежа, grant, очередь, ссылки на хранилище и технические ключи не передаются.

Для квалифицируемого synthetic promo-источника в той же транзакции сохраняется test-only право на зачёт **6 900 ₽**. Оно привязано к исходному отчёту, имеет срок действия по времени `Europe/Moscow`, не может быть автоматически списано и не включает платёжный провайдер, оплату, возврат либо реальное коммерческое обязательство.

## Инварианты безопасности

| Инвариант | Техническая реализация | Подтверждение |
|---|---|---|
| Один отчёт на один входной snapshot | Уникальные ограничения snapshot и fenced lease worker | Реальная MariaDB-приёмка |
| Неизменяемость готового отчёта | Ready payload, content hash и status защищены хранилищем и repository contract | Snapshot integration tests |
| Доступ только владельцу | Customer session → owner/case fence → готовый snapshot | Router и owner-matrix tests |
| Отсутствие публичной ссылки | Нет share/token URL, storage reference или bearer credential в DTO/UI | Client security tests и static scan |
| Право на зачёт не создаётся частично | Issue entitlement и ready snapshot выполняются в одной транзакции | Report worker DB acceptance |
| Нет LLM и внешнего PSP | В R1 report/credit модулях отсутствуют вызовы LLM, сети и платёжного провайдера | Static scan и release gates |

## Границы готовности

Инкремент готов для следующего технического этапа — PDF из того же snapshot. Он **не** разрешает клиентский запуск, реальную оплату, автоматическое списание зачёта, внешнюю отправку сообщений, публичный доступ к отчёту или юридическое утверждение содержания. Эти ограничения остаются fail-closed.
